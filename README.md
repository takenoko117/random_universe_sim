# Multiverse Creator (マルチバース・クリエイター)
### 宇宙の30大ハイパーパラメータ・多元宇宙シミュレーションゲーム

[![Deploy to GitHub Pages](https://github.com/takenoko117/random_universe_sim/actions/workflows/deploy-pages.yml/badge.svg)](https://github.com/takenoko117/random_universe_sim/actions/workflows/deploy-pages.yml)

🌐 **ブラウザで今すぐプレイ (GitHub Pages)**: [https://takenoko117.github.io/random_universe_sim/](https://takenoko117.github.io/random_universe_sim/)  
📦 **GitHub リポジトリ**: [https://github.com/takenoko117/random_universe_sim](https://github.com/takenoko117/random_universe_sim)

素粒子物理学の標準模型および宇宙論の標準模型において、未だその値の起源が解明されていない**約30種類のハイパーパラメータ（物理定数・結合定数・宇宙論密度など）**をランダムまたは手動で改変し、マルチバース（多元宇宙）仮説のもとで誕生する宇宙の運命や生命誕生の可能性をシミュレートするインタラクティブ・サイエンスゲームです。

---

## 🎮 主な機能とゲームシステム

1. **マルチバース・ルーレット（宇宙ガチャ）**
   - **微小ゆらぎ (±10%)**: 人間原理の限界領域を探索
   - **標準マルチバース (0.2x〜5.0x)**: 多様な物理法則のバリエーション
   - **超混沌カオス (10⁻⁴x〜10⁴x)**: 時空が壊れる極限の終末宇宙
   - ビッグバン・インフレーションのプロシージャル演出と自動命名システム

2. **デュアルスケール・リアルタイム観測（3D & 2D）**
   - **マクロビュー (Three.js 3D)**: 銀河の回転、暗黒物質コズミックウェブ、宇宙項や重力による膨張/収縮/引き裂かれのリアルタイム物理アニメーション
   - **ミクロビュー (Canvas 2D)**: クォークと核力束縛、二陽子結合、ボーア半径、電子軌道崩壊のダイナミック可視化

3. **30パラメータ・チューニングラボ**
   - 30種類すべてのパラメータを対数スライダーで微調整
   - 各定数の科学的意義、人間原理的微調整の理由、極限値の影響をツールチップで詳しく解説

4. **8段階の宇宙進化アセスメント**
   - 時空幾何学（3次元空間か）
   - 真空の安定性（ヒッグス自己結合とトップクォークによる真空崩壊判定）
   - バリオン数生成（物質と反物質の対消滅比率）
   - 核力と素粒子（ジプロトン災厄、重水素結合、陽子崩壊、ストレンジレット）
   - 宇宙膨張と構造形成（ビッグリップ、ビッグクランチ、コズミックウェブ）
   - 恒星と炉（核融合点火、恒星寿命、超新星爆発）
   - 炭素合成と化学進化（トリプルアルファ反応のホイル共鳴判定、有機化学）
   - 生命居住可能性（生命指数 0〜100、生命形態仮説の自動生成）

5. **探査図鑑・実績・URL共有**
   - 発見した宇宙の履歴保存（LocalStorage）
   - 特異な宇宙（ビッグリップ、中性子海、4次元崩壊など）のアンロック実績
   - URLハッシュによる宇宙のパラメータ共有機能

6. **Web Audio API プロシージャル宇宙音響**
   - ビッグバンの重低音轟音、素粒子生成時のサイン波、生命誕生時の神秘的な和音ファンファーレ、深宇宙アンビエントBGM

## 🔬 収録されている30大ハイパーパラメータ

| カテゴリ | 記号 | パラメータ名 | 主な物理的役割 |
|---|---|---|---|
| **時空・重力** | $G$ | 万有引力定数 | 星の形成、核融合圧力、ブラックホール形成 |
| | $c$ | 真空中の光速度 | 因果律の最高速度、$E=mc^2$ の変換効率 |
| | $\hbar$ | 換算プランク定数 | 量子力学的作用、不確定性原理、縮退圧 |
| | $\Lambda$ | 宇宙項 (暗黒エネルギー) | 宇宙の加速膨張、ビッグリップ vs ビッグクランチ |
| | $\Omega_{cdm}$ | 冷たい暗黒物質密度比 | 銀河の骨格、コズミックウェブの形成 |
| | $\Omega_b$ | 通常物質 (バリオン) 密度比 | 天体や生命を構成する通常物質の総量 |
| | $H_0$ | ハッブル定数 | 宇宙の初期膨張速度、宇宙年齢 |
| | $Q$ | 原始密度ゆらぎ振幅 | 銀河の種の密度ムラ（約10⁻⁵） |
| | $n_s$ | スカラー・スペクトル指数 | 大小スケールのゆらぎ分布のスケール不変性 |
| | $D$ | 空間次元数 | 安定した逆二乗則（D=3のみ安定軌道解が存在） |
| **電磁気・量子** | $\alpha$ | 微細構造定数 | 電磁気力の強さ、原子核と電子の結合 |
| | $m_e$ | 電子質量 | 原子のボーア半径、分子結合の柔軟性 |
| | $k_B$ | ボルツマン定数 | 熱運動と温度の変換、液体の安定領域 |
| | $\varepsilon_0$ | 真空の誘電率 | クーロン相互作用の係数 |
| | $\sigma_{SB}$ | ステファン・ボルツマン定数 | 黒体放射冷却、ハビタブルゾーン |
| **核力・素粒子** | $\alpha_s$ | 強い力の結合定数 | クォーク閉じ込め、ジプロトン問題 |
| | $G_F$ | フェルミ結合定数 | 弱い力、ベータ崩壊、超新星爆発 |
| | $m_u$ | アップクォーク質量 | 陽子と中性子の質量差（m_u > m_d で陽子崩壊） |
| | $m_d$ | ダウンクォーク質量 | 中性子の安定性 |
| | $m_s$ | ストレンジクォーク質量 | ストレンジ物質（ストレンジレット）の安定性 |
| | $v$ | ヒッグス真空期待値 | 全素粒子の質量スケール |
| | $\lambda_H$ | ヒッグス自己結合定数 | 電弱真空の安定性（真空崩壊リスク） |
| | $\sum m_\nu$ | ニュートリノ質量和 | ホットダークマター、自由運動減衰 |
| | $\theta_{QCD}$ | 強CP角 | 中性子電気双極子モーメント |
| **対称性・世代** | $\eta$ | バリオン非対称比 | 物質/反物質の対消滅生存比率 |
| | $m_\mu$ | ミューオン質量 | ミューオン触媒核融合、第2世代レプトン |
| | $m_\tau$ | タウレプトン質量 | 第3世代レプトン |
| | $m_{c,b}$ | 重いクォーク質量スケール | フレーバー混合 |
| | $m_t$ | トップクォーク質量 | ヒッグス真空安定性に直接影響 |
| | $\delta_{CP}$ | CP対称性の破れ位相 | 物質優勢宇宙の誕生起源（サハロフ条件） |
